# Sonar — автопостер крипто-новостей в Telegram

Бесплатный бот: раз в час забирает свежие заголовки из RSS крипто-изданий
и публикует их в твой Telegram-канал. Работает на GitHub Actions — сервер
держать не нужно, стоимость $0.

## Быстрый старт (10 минут)

1. **Создай бота.** В Telegram напиши `@BotFather` → `/newbot`, следуй
   подсказкам. В конце получишь токен вида `123456789:AAExxxxxxxxxxxxx`.

2. **Добавь бота админом** в свой канал (Settings → Administrators →
   Add Admin → выбрать бота → включить "Post Messages").

3. **Узнай chat_id канала.**
   - Если канал **публичный** — просто используй `@имя_канала` как
     `TELEGRAM_CHAT_ID` (со знаком `@`).
   - Если **приватный** — перешли любое сообщение из канала боту
     `@userinfobot`, он покажет числовой `chat_id` (обычно начинается с `-100`).

4. **Залей эту папку (`sonar_bot/`) в новый репозиторий на GitHub.**
   Публичный репозиторий — тогда Actions бесплатны без лимита минут.
   (Приватный тоже подойдёт, просто есть лимит ~2000 бесплатных минут/месяц —
   для одного запуска в час этого с большим запасом хватит.)

5. **Добавь секреты репозитория:**
   Repo → Settings → Secrets and variables → Actions → New repository secret
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `TELEGRAM_CHAT_ID` — значение из шага 3

6. **Готово.** Workflow в `.github/workflows/post_news.yml` сам запускается
   каждый час. Проверить вручную сразу: вкладка **Actions** в репозитории →
   выбрать workflow "Sonar — автопостинг новостей в Telegram" →
   **Run workflow**.

## Настройка

- Список источников — в начале `post_news.py`, переменная `FEEDS`.
  Добавляй свои RSS-ссылки туда же (проверь ссылку в браузере перед
  добавлением — некоторые издания меняют адрес RSS).
- `MAX_POSTS_PER_RUN` — сколько новостей публиковать за один запуск
  (по умолчанию 3, чтобы канал не заспамило, если бот не запускался долго).
- Расписание — строка `cron` в `post_news.yml`
  (`"7 * * * *"` = каждый час в 7 минут; синтаксис как у обычного cron).

## Важно

Это черновая лента, а не готовый контент-план. Голый автопостинг без
собственных комментариев подписчики быстро отписывают — используй его
как фон между своими постами, а не как замену им (подробнее — в плане
Sonar, раздел "Фаза 3").
